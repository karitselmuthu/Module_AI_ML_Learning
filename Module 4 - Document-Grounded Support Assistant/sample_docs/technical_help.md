# Demo technical help

The maximum upload size is **10 MB per file**. An HTTP 413 error means the uploaded file exceeds that limit; reduce the file size and retry.

If an integration stops syncing, reconnect it from **Settings > Integrations** and review the latest sync log. Do not share access tokens in a support ticket.

If an export times out, narrow the date range and retry. If it still fails, provide the export job ID to support.
