# Synthetic ticket samples

These CSVs are generated by `../generate_demo_data.py`. Every ticket text and ID is invented for learning; no customer records were copied. The wording is intentionally simple, so high scores on these files do not predict performance on real support traffic.

| File | Rows | Columns | Exercise |
|---|---:|---|---|
| `tickets.csv` | 120 | `text`, `label` | Basic three-class training and predictions |
| `production_style_tickets.csv` | 600 | `ticket_id`, `subject`, `body`, `label`, `scenario_id` | Combine subject and body; keep scenario variants in one split |
| `real_style_tickets_v2.csv` | 603 | `text`, `label`, `agent_routed_queue` | Compare issue versus route targets; audit one unsupported label and a conflicting route pair |

Use `python generate_demo_data.py --force` from the Module 1 folder to recreate these exact examples. To use your own dataset, place it in the ignored `data/` folder or pass its path with `--data`.
